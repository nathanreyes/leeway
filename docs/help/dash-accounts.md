# Accounts

Accounts are your real balances right now — checking and credit cards. This is the ground truth the whole forecast builds up from.

## How it fits

Leeway trusts your actual balance rather than a running tally of transactions. A checking buffer is money you hold back; a card's carried balance folds into what's left. Accounts apply only to the current month.

## Example

```
  Checking   balance 2,400   buffer 200
  Visa       owed    -320    carry  0

  What's left starts from 2,400, minus
  the 200 buffer you're keeping aside.
```
