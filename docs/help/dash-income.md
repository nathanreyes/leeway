# Income

Income lists the money you expect to arrive this month — paychecks, transfers, deposits.

## How it fits

Each row is either still expected or already received. Because Leeway forecasts the whole month, expected income already lifts what's left; marking a row received just confirms the money landed, it doesn't change the total.

## Example

```
  Paycheck        2,000   received
  Side invoice      600   expected

  Both already count toward what's left;
  'received' is just your confirmation.
```
