# Plans

Plans are reusable monthly templates. Each bundles the income, bills, and envelopes of a typical month.

## How it fits

Stamp a plan into a month to create an independent snapshot you can then adjust freely. Editing a plan afterwards doesn't touch months you've already stamped — a plan is the starting point, not a live link.

## Example

```
  Monthly baseline
    income 2,750 · bills 1,660 · env 800

  Stamp -> creates August, ready to toggle.
  Edit later -> August is unaffected.
```
