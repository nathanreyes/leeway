# Plan · Expenses

The recurring bills of a plan — the fixed costs of a typical month, ready to stamp into any month.

## How it fits

These become 'to pay' bills when the plan is stamped. The amounts here are the plan's defaults; each stamped month keeps its own copy you can adjust without touching the template.

The stamp review can replace a default with a settled amount from prior months. It remembers the source you pick. If that source has no data, the static plan amount wins for that stamp.

A bill that arrives once or twice a year — an insurance premium, a registration fee — gets its months from `M`, and only stamps in those.

## Example

```
  Plan: Monthly baseline
    Rent        1,500
    Internet       80

  Stamp -> the month opens with these bills.
```
