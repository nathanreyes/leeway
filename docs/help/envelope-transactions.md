# Envelope · Transactions

The individual entries recorded against this envelope.

## How it fits

For a manual envelope, these transactions are exactly what determines how much you've consumed. For an automatic envelope they're a log for your own reference — the balance is driven by the calendar, not by these rows.

## Example

```
  Groceries
    -42.10   Trader Joe's
    -18.75   corner store

  Manual: these set consumed.
  Automatic: reference only.
```
