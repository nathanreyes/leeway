# Plan · Income

This is the income side of a plan — a reusable template for a typical month, not a live month itself.

## How it fits

Stamp the plan into a month from the sidebar to copy this income in as toggleable rows. Editing the plan later never rewrites months you've already stamped.

The stamp review can replace a default with settled income from prior months. It remembers the source you pick. If that source has no data, the static plan amount wins for that stamp.

Income that only arrives some months — a year-end bonus, seasonal work — gets its months from `M`, and stamps only in those.

## Example

```
  Plan: Monthly baseline
    Paycheck     2,000
    Rental inc.    750

  Stamp -> August starts with these.
```
