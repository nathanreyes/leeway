# Plan · Income

This is the income side of a plan — a reusable template for a typical month, not a live month itself.

## How it fits

Stamp the plan into a month (from the Plans list) to copy this income in as toggleable rows. Editing the plan later never rewrites months you've already stamped.

## Example

```
  Plan: Monthly baseline
    Paycheck     2,000
    Rental inc.    750

  Stamp -> August starts with these.
```
